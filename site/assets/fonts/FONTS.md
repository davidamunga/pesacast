# Fonts

On Apple devices the site uses the system font (SF Pro), which needs no file. Everywhere else it falls back to Public Sans, which is self-hosted here so the site loads nothing from other websites.

| Font | Use | Licence |
|---|---|---|
| Public Sans (variable, Latin subset) | Fallback for text and headings | SIL Open Font License 1.1, Copyright 2015 The Public Sans Project Authors (https://github.com/uswds/public-sans) |

The licence text is at https://openfontlicense.org/. The file is the Latin variable build distributed by Fontsource (https://fontsource.org), unmodified.
